# Contributing

Thanks for helping improve Faster Stacked Tabs.

## Reporting issues

Please include your operating system, app version, theme, and the steps needed
to reproduce the problem. If the issue involves another plugin, note whether it
still occurs when that plugin is disabled.

## Development

1. Install dependencies with `npm install`.
2. Run `npm run dev` while developing.
3. Run `npm run lint`, `npm run typecheck`, and `npm run build` before opening a
   pull request.

Keep changes focused and avoid unrelated formatting changes.
